# hive coding

The public GitHub home for hive coding, from [The Hive Code](https://thehivecode.ai/?ref=github).

What it does today:

- States what hive coding is, in the same words as the Learn pages, and points at them
- Ships a HIVE.md template, three examples, and a CLI that writes and checks the file

What is next:

- Publish the `thehivecode` command to npm once the name is claimed by this project
- Grow the resource list with links someone has actually opened

How to help:

- Read [CONTRIBUTING.md](CONTRIBUTING.md). Add a resource only after you have opened the page.
