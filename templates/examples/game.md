# Hex Lamp

An example HIVE.md for a game. Not a live project.

Light a path from the entrance to the hive by flipping hexes. It runs in the browser and keeps the best score on this computer. There is no account.

`deploy` is omitted. GitHub Pages and itch.io are not values the field accepts. The field is `vercel`, `netlify`, or both.

What it does today:

- One board and three levels

What is next:

- Level changes a player asks for, after a person accepts the suggestion and reviews the pull request

How to help:

- Play a level and describe the move where you got stuck
