# Saturday Run Sheet

An example HIVE.md for a web app. Not a live project. Copy the shape and replace the words.

A one-page sign-up for a club's weekly run. Members see the meeting point and add a first name. Emails and phone numbers stay off the page.

What it does today:

- Lists this week's run and the first names already down
- Lets a member add or remove their own name

What is next:

- Whatever the club asks for in public, one suggestion at a time, after a maintainer accepts it

How to help:

- Use it on a real Saturday and say what was missing
