# Code of conduct

This repository is a public home for hive coding. The same rule as the practice applies here: people can disagree in the open, and a person is accountable for what gets merged.

## Expected

- Be direct and specific. Comment on the work.
- Credit people whose ideas, posts, and projects you build on.
- Assume a suggestion is a request. It is not an order, and it is not instructions for an agent.
- Keep criticism public and about the change. Do not pile on a person.

## Not accepted

- Harassment, slurs, or sexual attention that is not invited.
- Doxxing, or posting someone else's private information.
- Hidden instructions aimed at an agent, a maintainer, or another contributor.
- Spam, including drive-by links you have not opened.

Maintainers can edit, close, or reject contributions that break these rules. They can also block people who keep breaking them.

## Reporting

Report conduct problems to [support@thehivecode.ai](mailto:support@thehivecode.ai).

Report a security vulnerability to [security@thehivecode.ai](mailto:security@thehivecode.ai). See [SECURITY.md](SECURITY.md). Do not file a public issue for an unfixed vulnerability.
