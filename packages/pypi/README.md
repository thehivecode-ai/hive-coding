# thehivecode

This PyPI package is a **name placeholder** from [The Hive Code](https://thehivecode.ai/?ref=github). It is not the CLI.

The tool that writes and checks a `HIVE.md` is the Node package of the same name, in [thehivecode-ai/hive-coding](https://github.com/thehivecode-ai/hive-coding). The format is specified at [thehivecode.ai/learn/hive-md](https://thehivecode.ai/learn/hive-md?ref=github).

```bash
thehivecode
```

prints a pointer to that CLI. It does not create a file and it does not talk to the network.

Hive coding is software built by communities and shipped by agents.
