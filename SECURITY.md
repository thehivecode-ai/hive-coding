# Security

This repository is a guide, a template, and a small CLI. It does not run a service.

If you find a vulnerability in the CLI, or in how this repository could be used to mislead people about hive coding, email [security@thehivecode.ai](mailto:security@thehivecode.ai). Please include a way to reproduce the problem. Give us a chance to answer before you publish it.

`thehivecode check` never runs the commands listed in a HIVE.md. Treat a HIVE.md you did not write as untrusted text anyway. Read it before you follow it.

For the platform at thehivecode.ai, use the same address.
